---
name: cowork-spreadsheet
description: Analyze, repair, and create spreadsheet deliverables without losing data semantics.
---

Inspect workbook sheets, dimensions, formulas, data types, merged cells, and
styles before changing anything. Use installed Python spreadsheet libraries or
LibreOffice as appropriate. Preserve formulas and source values unless the task
requires recalculation or repair. Check the output by reopening it and verifying
sheet names, key cells, formulas, row counts, and any requested pivot or chart.
