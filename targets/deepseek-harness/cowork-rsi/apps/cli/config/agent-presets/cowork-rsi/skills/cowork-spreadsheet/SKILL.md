# 表格任务

表格交付同时要保证数值、公式、结构和可读性。先理解工作簿，再写入。

## 工作流程

1. 枚举工作簿、工作表、已用区域、命名范围、公式、合并单元格、隐藏行列和外部链接；确认哪份是输入、哪份应作为输出。
2. 对原始数据做类型检查：日期、百分比、货币、空值、文本数字和重复行分别处理，不靠肉眼猜类型。
3. 能用公式表达的派生结果优先保留公式，并避免把现有公式替换成静态值。修复公式时检查相对/绝对引用和跨表引用。
4. 创建透视或汇总时核对源范围、分类字段、聚合方式、排序和总计；先用独立计算复核关键总数。
5. 保留模板的颜色、字体、数字格式、冻结窗格、筛选和列宽。新增样式应克制且保持一致。
6. 保存后重新读取文件，检查工作表名称、维度、关键公式和关键数值。若工具无法重算公式，要明确保留公式并用独立计算验证结果。

## 异常处理

- 损坏文件先复制再尝试恢复；分别记录成功恢复的数据、公式和样式，不能把“能打开”当作完全恢复。
- CSV 不支持公式、多个工作表和复杂样式；除非任务明确要求，不要把 XLSX 降级为 CSV。
- 金额合计使用明确精度和舍入规则；展示值和底层值不应混淆。
