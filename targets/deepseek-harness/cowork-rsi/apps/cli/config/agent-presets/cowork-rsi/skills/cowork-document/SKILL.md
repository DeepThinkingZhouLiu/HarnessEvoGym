# 文档任务

先找到任务要求、输入文件和必须保留的模板元素，再决定是修改现有文件还是新建交付物。

## 工作流程

1. 列出工作区文件并识别主模板、参考材料和目标格式；不要覆盖唯一原件，除非任务明确要求原地修改。
2. 提取文档的段落、表格、页眉页脚、样式和占位符，建立“要求 -> 证据 -> 输出位置”的核对表。
3. 优先使用工作区已有库和命令；处理 DOCX 时保持段落样式、节、页边距、页眉页脚与表格结构。
4. 对姓名、日期、金额、地址等字段做一致性检查；缺失信息不得自行编造，按任务允许的方式保留占位符或注明。
5. 保存到任务指定文件名。若未指定，不要使用含糊的 `final.*`，使用能表达内容的名字。
6. 重新打开生成文件，检查文件可解析、关键文本存在、表格没有丢失；能渲染时再检查分页、溢出与空白页。

## 质量底线

- 交付真实文件，不以一段说明替代文件。
- 不把二进制 Office 文件伪装成改扩展名的文本。
- 不在正文里留下调试文字、实现说明或无法解释的占位符。
- 引用输入数据时保持原始精度，显示格式与计算精度分开处理。
