# PDF 任务

PDF 的文本层和视觉层可能不一致，重要任务必须同时检查两者。

## 工作流程

1. 识别 PDF 是否包含可提取文本、扫描图像、表单域、附件或加密；记录页数和页面尺寸。
2. 文本抽取后保留页码来源。扫描件先做 OCR，再抽样对照原页，尤其检查数字、小数点、负号和表头。
3. 表格抽取不能只看行数；核对跨页表头、合并单元格、列错位、空值和总计。
4. 生成 PDF 时从可维护的源文件导出，嵌入字体，并检查链接、书签、页眉页脚和分页。
5. 比较 PDF 与表格或文档时，分别比较结构化值和视觉呈现；差异报告应指出页面、字段、原值和新值。
6. 最终重新打开 PDF，检查页数、关键文本、损坏对象和空白页；能渲染时抽查首尾页及包含关键表格的页面。

## 安全与准确性

- 不把 OCR 结果当成无误原文。
- 不移除签名、权限或元数据，除非任务明确要求且允许。
- 涉及金额和合同字段时，保留原始字符串并单独给出规范化值。
