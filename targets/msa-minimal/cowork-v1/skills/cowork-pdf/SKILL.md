---
name: cowork-pdf
description: Inspect, create, convert, and validate PDF deliverables.
---

Determine whether the task requires extracting content from an existing PDF or
creating a new PDF. Prefer installed PDF libraries and LibreOffice over manual
binary manipulation. When generating a PDF, verify the file exists, has a
non-zero page count, and contains the expected text or visual assets. Keep
temporary renderings out of the final submission unless explicitly requested.
