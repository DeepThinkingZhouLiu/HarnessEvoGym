# 演示文稿任务

先识别内容目标和视觉参考，再按“故事线 -> 页面职责 -> 视觉层级 -> 文件核验”完成交付。

## 工作流程

1. 检查已有 PPTX、参考截图、品牌素材和数据文件；记录页面尺寸、字体、主色、边距、标题位置和重复组件。
2. 为每页定义一句核心结论，避免把原始材料整段贴进页面。数字、图表和正文必须能追溯到输入材料。
3. 优先复用模板母版和现有布局；新增元素要对齐、留白一致，标题层级和字号一致。
4. 图表选择服务于结论，轴、单位、图例和数据标签必须清晰；不要用装饰性图表掩盖数据。
5. 检查文本溢出、元素越界、对象遮挡、低分辨率图片和空占位符。
6. 保存后重新解析页数和关键文本；能渲染时生成预览并逐页检查，修复后再次渲染。

## 质量底线

- 不把每页做成密集文字墙。
- 不随意改变参考模板的页面比例、品牌颜色和字体体系。
- 不以图片拼接冒充可编辑的演示文稿，除非任务明确要求纯图片页。
- 最终目录只保留任务要求的交付物和必要附件，不遗留调试预览。
